OpenONDA

A modular CFD framework that unifies a GPU-accelerated vortex-particle method with a finite-volume method and an OpenFOAM interface. It provides an extensible Python/C++ architecture for hybrid external-flow simulation and in-line solver control.

  • C++
  • CUDA
  • OpenFOAM
  • Hybrid CFD
